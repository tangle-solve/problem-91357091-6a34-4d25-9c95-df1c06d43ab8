### ALGO-000042: Arithmetic formulas versus branching programs
- **Subfield:** Algebraic complexity and polynomial identity testing
- **Open:** Prove or refute that polynomial-size arithmetic formulas and polynomial-size algebraic branching programs compute the same polynomial families.
- **Status:** Open in the unrestricted commutative setting. Formula lower bounds for determinant or iterated matrix multiplication strong enough to separate these classes remain unavailable.
- **Type:** theory
- **Why:** Determines how much benefit arithmetic computation obtains from sharing subcomputations along different paths.
- **Key works:** Valiant et al. (1983), *Fast Parallel Computation of Polynomials Using Few Processors*; Shpilka–Yehudayoff (2010).
- **Related:** Symbolic computation—expression swell; automatic differentiation—compact derivative representations.
